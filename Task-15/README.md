# Task 15 — Sales Performance Dashboard

A second full dashboard page, this time built around a quick performance snapshot rather than deep trend analysis.

## What I Did

**Page setup:** Created a new page named **Sales Performance Dashboard**.

**KPI row:** Added KPI visuals for Total Sales, Total Order Quantity, and Total Orders, aligned horizontally along the top with consistent formatting, and renamed them `KPI_TotalSales`, `KPI_TotalQuantity`, `KPI_TotalOrders`.

**Bar chart:** Built a Bar Chart with Product Category on the axis and Total Sales as the value, sorted descending with data labels turned on so the ranking is obvious at a glance. Renamed it `BAR_SalesByCategory`.

**Donut chart:** Added a Donut Chart with Product Category in the legend and Total Sales as the value, with percentage labels enabled and the legend placed clearly. Renamed it `DONUT_CategoryContribution` — a nice complement to the bar chart, showing proportion rather than absolute rank.

**Slicers:** Added Year and Region/Continent slicers in dropdown style, synced across the page, and renamed clearly so anyone opening the file understands what each one controls.

**Layout check:** Made sure all the visuals actually responded correctly to the slicers, checked alignment and spacing, and cleaned up anything that felt cluttered.
